# Stemkye — sitio web

Páginas públicas de la app Stemkye, servidas con GitHub Pages:

- `index.html` — inicio
- `privacy.html` — Política de privacidad
- `terms.html` — Términos y condiciones
- `receiver/` — receptor de Google Cast para enviar el karaoke a la TV

Publicación: Settings → Pages → Source "Deploy from a branch", rama `main`, carpeta `/ (root)`.
